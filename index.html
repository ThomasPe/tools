Lumia & Windows 10 Mobile Living Images

Convert legacy Windows Phone 8.1 & Windows 10 Mobile Living Images (.jpg + .mp4.thm and *_LI.jpg) into modern Google Pixel & Windows 11 Motion Photos (Android Motion Photo 1.0).

  • Dual-Resolution: Pairs both 5MP & PureView full-res
  • Windows 10 Mobile embedded ZIP (_LI.jpg) support
  • Preserves 100% original camera EXIF metadata
  • Folder-to-folder streaming via File System Access API
